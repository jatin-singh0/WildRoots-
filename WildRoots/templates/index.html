About Project

Objective

WildRoots shows how a singly linked list can store, search, filter and classify data. Plants and animals are matched to an environment using a simple scoring method – no machine learning, no database.

Technology used

Python + Flask (backend), HTML, CSS and JavaScript (frontend), and a hand-written Linked List.

What is a Linked List?

A chain of nodes. Each node stores one species and a pointer to the next node. To find something, we start at the head and follow the pointers until the end (None).

How classification works

For each node we compare 5 features (habitat, temperature, pollution, water, climate). Score = matching features ÷ 5 × 100. Species scoring 40% or more are shown, best first.

Linked list visualization

HEAD points to the first node. Each node points to the next one. The last node points to None.
